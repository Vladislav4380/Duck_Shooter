# Eye Oracle AI: Project Architecture

## 1. Introduction

This document outlines the architecture of the "Eye Oracle AI" Telegram Mini App. The application provides an entertainment service where users can upload eye photos to receive mystical horoscopes generated by AI. The design adheres to a "Mystic Cyberpunk" aesthetic, featuring dark backgrounds, neon accents, glowing effects, animated scanners, particles, stars, and a HUD-like interface to evoke an "AI destiny scanner" feel.

## 2. High-Level Architecture

The application follows a client-server architecture, consisting of:

*   **Frontend (Telegram Mini App):** An Angular application embedded within Telegram, responsible for user interaction, image capture/upload, and displaying results.
*   **Backend (Web API):** A .NET 8 Web API that handles Telegram `initData` validation, image processing (simulated), AI integration, and data persistence.
*   **AI Service:** An external AI model (e.g., OpenAI GPT-4o) that generates horoscope predictions based on eye image analysis.
*   **Database:** PostgreSQL, used for storing scan records and user history.

```mermaid
graph TD
    A[Telegram User] -->|Opens Mini App| B(Telegram Mini App Frontend)
    B -->|Uploads Eye Photo & initData| C(Backend API)
    C -->|Validates initData| D{Telegram Auth Service}
    C -->|Stores Scan Record (Pending)| E(PostgreSQL Database)
    C -->|Enqueues Scan Request| F(Scan Queue Service)
    F -->|Retrieves Image URL| G(Image Storage - e.g., S3)
    F -->|Sends Image & Prompt| H(AI Service)
    H -->|Returns Horoscope JSON| F
    F -->|Updates Scan Record (Completed)| E
    B -->|Polls for Result| C
    C -->|Returns Horoscope Result| B
    B -->|Displays Horoscope| A
```

## 3. Frontend (Angular Telegram Mini App)

### 3.1. Technology Stack

*   **Framework:** Angular
*   **Language:** TypeScript
*   **Styling:** SCSS with Mystic Cyberpunk theme, glowing effects, and animations.
*   **Telegram Integration:** Telegram WebApp SDK
*   **HTTP Client:** Angular's HttpClient (or Axios)
*   **Localization:** Custom `LocalizationService` for English and Ukrainian.

### 3.2. Key Features

*   **Responsive Mobile-First UI:** Optimized for Telegram's mobile environment.
*   **Telegram Theme Compatibility:** Adapts to Telegram's dark/light themes.
*   **Localization:** Supports English and Ukrainian languages, with dynamic switching.
*   **Secure Image Upload:** Handles image capture/upload and sends to the backend.
*   **Error Handling & Loading States:** Provides clear feedback to the user during asynchronous operations.
*   **History Storage:** Displays past horoscope predictions based on Telegram user ID.
