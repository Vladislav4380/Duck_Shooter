# Duck Shooter - Telegram Mini App Game

## Проект успешно создан! 🎉

Это полнофункциональная игра "Duck Shooter" (Мисливець на Качок) для Telegram Mini App, разработанная на Angular с TypeScript.

## 📋 Что включено в проект

### Компоненты:
- **StartScreenComponent** - Стартовый экран с правилами и лучшим результатом
- **GameScreenComponent** - Основной игровой экран с утками
- **ResultScreenComponent** - Экран результатов с возможностью поделиться

### Сервисы:
- **GameService** - Управление игровой логикой, состоянием и механикой
- **LanguageService** - Поддержка украинского и английского языков
- **TelegramService** - Интеграция с Telegram WebApp API

### Функциональность:
✅ **Игровая механика:**
- Утки летят с разных сторон экрана
- 3 типа уток: обычная (+10), быстрая (+25), золотая (+50 очков)
- Таймер 60 секунд
- Отслеживание попаданий, промахов и точности
- Сохранение лучшего результата в localStorage

✅ **Дизайн:**
- Cartoon/retro arcade стиль
- Яркие цвета и плавные анимации
- Полностью адаптивный для мобильных устройств
- Поддержка viewport-fit для notch-дизайна

✅ **Многоязычность:**
- Украинский и английский языки
- Автоматическое определение языка Telegram пользователя
- Переключатель языка на стартовом экране

✅ **Интеграция с Telegram:**
- Получение данных пользователя (ID, имя, язык)
- Кнопка поделиться результатом
- Полная поддержка Telegram WebApp API

## 🚀 Установка и запуск

### Требования:
- Node.js 22.13.0 или выше
- pnpm (или npm/yarn)

### Шаги:

1. **Перейдите в директорию проекта:**
   ```bash
   cd Duck_Shooter
   ```

2. **Установите зависимости:**
   ```bash
   pnpm install
   ```

3. **Запустите dev-сервер:**
   ```bash
   pnpm start
   ```
   или
   ```bash
   pnpm ng serve
   ```

4. **Откройте браузер:**
   ```
   http://localhost:4200
   ```

## 📦 Сборка для продакшена

```bash
pnpm run build
```

Собранные файлы будут в директории `dist/duck-shooter/`.

## 🎮 Как играть

1. Нажмите кнопку "Почати гру" / "Start Game"
2. Тапайте по уткам, чтобы набирать очки
3. Обычная утка = 10 очков
4. Быстрая утка (с дымом) = 25 очков
5. Золотая утка (с блеском) = 50 очков
6. Игра длится 60 секунд
7. После окончания посмотрите результаты и поделитесь ими

## 🌐 Развертывание в Telegram

### Для локального тестирования:

1. Используйте Telegram Bot API для создания Mini App
2. Укажите URL вашего приложения в параметрах бота
3. Откройте Mini App через Telegram

### Для продакшена:

1. Соберите проект: `pnpm run build`
2. Загрузите содержимое `dist/duck-shooter/` на ваш сервер
3. Убедитесь, что сервер поддерживает HTTPS
4. Настройте CORS если нужно
5. Укажите URL в параметрах Telegram бота

## 🎨 Кастомизация

### Изменение времени игры:
В `src/app/services/game.service.ts` измените:
```typescript
private readonly GAME_DURATION = 60; // в секундах
```

### Изменение очков за уток:
В методе `getPointsForDuck()` в `game.service.ts`:
```typescript
case 'normal': return 10;   // Измените значение
case 'fast': return 25;
case 'golden': return 50;
```

### Изменение интервала появления уток:
```typescript
private readonly DUCK_SPAWN_INTERVAL = 800; // в миллисекундах
```

## 🐛 Известные ограничения

- Звуки работают только в браузерах с поддержкой Web Audio API
- На некоторых устройствах могут быть проблемы с производительностью при большом количестве уток одновременно
